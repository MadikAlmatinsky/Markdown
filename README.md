# Менің оқу жобам

Бұл жоба бағдарламалау және Git жүйесімен жұмыс істеуді үйрену мақсатында жасалды.

## Жоба туралы

Жоба барысында келесі технологиялармен жұмыс жасалды:

- Python
- C#
- HTML
- CSS
- Git
- GitHub
- SQL

## Қолданылған технологиялар

| Технология | Қолданылу мақсаты |
|---|---|
| Python | Бағдарламалау |
| C# | Консольдік бағдарламалар жасау |
| HTML | Веб-беттер жасау |
| CSS | Веб-бетті безендіру |
| Git | Нұсқаларды басқару |
| GitHub | Жобаны сақтау |
| SQL | Деректер қорымен жұмыс |
